# Archived infographics

These files are historical design artifacts. They are not current learning content and must not be
published, indexed as authoritative evidence, or used to answer factual questions.

In particular, the archived entropy images predate the September–October 2026 standards review and
contain obsolete or incorrect claims about XOF_DRBG, fixed entropy/security-strength requirements,
source combining, and the CMVP Entropy Source Validation process. The maintained entropy infographic
is `public/images/infographics/pqcstd_entropy-randomness.png`.
