### What This Is About

A closer look at FIPS 140-3, the US and Canadian standard for cryptographic modules — usually the first certificate a hardware security module (HSM) meets. It builds on the certification fundamentals module; payment approval (PCI) has its own module.

### Why It Matters

Passing algorithm tests is only the first step toward FIPS 140-3; the module certificate is a separate result. Adding post-quantum algorithms changes the module, so it needs a new validation route.

### The Key Takeaway

A queue position is not a certificate: a module is "in progress" only when NIST lists it, and certified only once NIST issues a FIPS 140-3 certificate.

### What's Happening

As of 24 September 2026, the FIPS 140-3 standard itself is unchanged, while a US executive order directs NIST to speed up its validation process by about 19 December 2026.
