## libbitcoinpqc

- **Category**: Blockchain & DLT Protocols
- **Product Name**: libbitcoinpqc
- **Product Brief**: A C library for Post-Quantum Cryptographic (PQC) signature algorithms for Bitcoin, implementing ML-DSA-44, SLH-DSA, and BIP 340 Schnorr.
- **PQC Support**: Yes (with details)
- **PQC Capability Description**: Implements two NIST-standardized PQC signature algorithms: ML-DSA-44 (FIPS 204, lattice-based) and SLH-DSA-SHA2-128s (FIPS 205, stateless hash-based). It provides key generation, signing, and verification functions with a unified C API.
