## Cloudflare Workers

- **Category**: Cloud Encryption Gateways
- **Product Name**: Cloudflare Workers
- **Product Brief**: Serverless developer platform (built on the workerd runtime) that now exposes ML-KEM and ML-DSA post-quantum primitives through the Web Crypto API.
- **PQC Support**: Yes — opt-in ML-KEM and ML-DSA in Workers Web Crypto behind the webcrypto_modern_algorithms compatibility flag
- **PQC Capability Description**: Workers adds post-quantum Web Crypto algorithms from the WICG Modern Algorithms draft: ML-KEM-768/1024 and ML-DSA-44/65/87, plus encapsulate/decapsulate APIs, getPublicKey(), SubtleCrypto.supports() and JWK import/export.
