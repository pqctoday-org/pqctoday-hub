# pqc-references

This folder holds PQC Today's own extractions of published documents (for example
`regional-transition-dates/*.yaml` and `framework-2.1.json`). It does not hold the
documents themselves: third-party documents are not redistributed in this repository.
Read each document at its publisher's link.
